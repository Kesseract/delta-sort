# ゲーム（現行仕様）

試験管に入った液体を色ごとに分けるパズル。色はすべて、隣り合う色とR・G・Bのうち1つの成分だけが1違う。ほぼ見分けられないことがネタの中心。

## 遊び方

- URLを開くと、タイトル画面なしで即座に問題が始まる。
- 試験管をクリック（タップ）して選び、注ぎ先の試験管をクリックすると注げる。
  - 注げるのは、注ぎ先が空か、注ぎ先の一番上が同じ色で、空きがあるとき。
  - 一番上から続く同じ色を、入るだけまとめて注ぐ。これを1手と数える。
  - 選んだ試験管をもう一度クリックすると選択を外せる。注げない先をクリックすると、そちらを選び直す。
- すべての試験管が「空」か「1色で満杯」になればクリア。
- 取り消し（Zキー）で1手ずつ戻せる。戻した手は手数から引く。
- やり直し（Rキー）で問題の最初の状態に戻せる。手数は0に戻り、時間は止めずに続ける。
- ハード（設定）では、違う色の上にも注げる。注ぐ量・容量・クリア条件は同じ。

## 色

- ベース色は、色相をランダムに選び、彩度60%・明度50%のHSLからRGBへ変換して決める。
- 動かす成分（R・G・Bのどれか1つ）を問題ごとにランダムに選ぶ。並び全体を通して、それ以外の2成分は固定。
- 色の数をnとすると、ベース色から動かす成分を1ずつn−1回ずらしてn色を作る。0〜255を超える場合は逆向き（−1ずつ）にずらす。
- 液体は完全な単色で塗る。光沢・グラデーション・半透明を液体に重ねない（色の値が変わり、1の差が消えるか、逆に手がかりになるため）。ガラスの描写は液体の外側だけにする。

## 画面

- プレイ画面: 上に手数・経過時間・取り消し・やり直し・設定。中央に試験管。下に正解の色。
- 正解の色: n色を並びの順に矢印でつないで表示する。設定でオン・オフできる。
- 遊び方: 正解の色の下に、どういうゲームかの1文と操作・ルールの短い箇条書きを常に表示する。
- ハイライト（設定でオンのとき）: 選んだ試験管の、一番上から続く同じ色の部分の外側（ガラスの左右）に光る線を出す。液体の上や隣の試験管の液体には光を重ねない。
- 経過時間は最初に注いだときから数え始め、クリアで止まる。
- クリア表示: 盤面の上に重ね、ランク・手数・最短手数・時間と「次の問題」ボタンを出す。
  - ランクは手数÷最短手数で決める。S=最短と同じ、A=1.15倍以内、B=1.4倍以内、C=それより多い。
- 「次の問題」で、同じ本数の別の問題と新しい色（ベース色を固定していなければ）で始まる。
- クリア表示はEscでは閉じない。ブラウザの都合で閉じた場合も次の問題へ進む（解けた盤面を残さない）。
- 問題データを読み込めなかったときは、盤面の位置に再読み込みを促す文を出す。

## 設定

- 試験管の本数: 6／8／10／12／14本から選ぶ。空きの試験管は常に2本なので、色の数は本数−2。容量は4。初期値は10本。
- ベース色: ランダム（初期値）か、色相環をクリックして色相を固定する。固定中も動かす成分は毎回ランダム。
- 正解の色の表示: オン（初期値）／オフ。
- ハイライト: オン／オフ（初期値）。切り替えても問題は作り直さない。
- ルール: 普通（初期値）／ハード。変えるとその場で新しい問題になる。
- ハイライトとルールは、設定画面に説明の図を出す。
- 本数・ベース色・ルールを変えると、その場で新しい問題になる。今と同じ値を押したときは何もしない。
- 設定はブラウザに保存し、次に開いたときも使う。

## 問題と最短手数

- 問題は、本数ごとに事前に生成して最短手数まで解いた固定セット（目安200問）から選ぶ。ブラウザ側で探索はしない。
- 問題は色番号の並びだけを持ち、色は描画のときに当てはめる。
- 直前と同じ問題は続けて出さない。
- 各問題は普通とハードの最短手数を両方持つ。ランクと「最短」表示は今のルールの値を使う。ハードの最短は普通以下。
- 生成時に、最初から解けている問題と、最短手数を求めきれなかった問題は捨てる。

## 公開

- ビルドなしの静的ファイル（HTML・CSS・JavaScriptモジュール）として、GitHub Pagesで公開する。リポジトリ名は `delta-sort`。`main` へのpushでテストを通してから `site/` を配備する（リポジトリ設定の Pages の Source は「GitHub Actions」）。
- 問題の生成・求解とテストはNode.jsのスクリプトで行い、生成結果（JSON）をリポジトリに含める。

## スコープ外

- タイトル画面、レベル進行、操作を順に教えるチュートリアル
- ランキング、記録の保存、URLでの問題・結果の共有
- 色の差（1以外）の設定
- 色の違いそのものを強調する補助、RGB値の表示（ハイライトは選んだ試験管のつながりを示すだけ）
- 同じ色がくっついたときの演出（見分けのヒントになるため）
- 効果音・BGM

## 決定記録

- 2026-11-25 差は常に1で固定し、差の大きさの設定は持たない。理由: ネタの中心が「1の差」なので、練習用の段階は不要と本人が判断。
- 2026-11-25 動かす成分は1つだけにし、R→G→Bと回さない。理由: 仕組みが分かりやすく、正解の色の表示が単純なグラデーションになる。
- 2026-11-25 問題は事前に解いた固定セットから出す。理由: 最短手数を必ず正しくするため。毎回ランダム生成だと本数が多いとき最短を保証できない。
- 2026-11-25 URLでの共有はしない。理由: 本人が不要と判断。
- 2026-11-25 ハイライトは選んだ試験管だけ、初期値オフ。理由: 本人の選択。全試験管に出すと見分けの手間がほぼ無くなる。
- 2026-11-25 ルールは普通とハードを設定で選ぶ。理由: 普通では「注げない＝違う色」という手がかりで総当たりできる。ハードはそれが無く、目で見分けるしかない。
- 2026-11-25 ソルバーの下限を「一番下以外の区切りの数＋同じ色が複数の底にある分」にした。理由: ハードの14本で旧下限ではメモリが尽きた。
